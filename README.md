# MOROW — Maintaining Our Rights of Way

> **⚠️ This repository has moved.**
>
> Active development is on **Codeberg**: https://codeberg.org/morow/morow
>
> This GitHub repository is archived and no longer maintained.
> Please open issues, submit pull requests, and watch the project at Codeberg.

---

MOROW is an open source, cross-platform mobile app that gamifies walking Public Rights of Way (PRoW) across the UK — encouraging people to use lesser-walked footpaths whilst contributing GPS traces and map quality data back to OpenStreetMap.

See the active repository for full details: https://codeberg.org/morow/morow
